OpenCV DNN Super-Resolution Binary Models (.pb) Notice
========================================================================

This application distributes pre-trained, frozen TensorFlow (.pb) binary 
weights for image super-resolution, natively compatible with OpenCV's 
'dnn_superres' module. These files are not part of the app core but used as options and for demonstration only.

These files were generated during the 2019 Google Summer of Code (GSoC) 
program for the OpenCV organization.
