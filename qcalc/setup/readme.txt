Do not modify any files in this directory.
This helps prevent your changes from being overwritten by Git.

If you need to modify a file, copy it to the `qcalc/.setup` directory instead.
Rename the file if necessary (especially `template_*` files, should generally be renamed).

Files that you modify in `qcalc/.setup` are intended for your local customizations
and will not be replaced by future updates.

It is recommended to create local copy in `qcalc/.setup` folder and replace any
hard coded path with your local installation path
