A place to calculate, create, and share

Calculations are everywhere. Some are simple enough for a pocket calculator, while others involve formulas, units, data, charts, simulations, or specialized technical knowledge. Many useful calculations are too specific to justify building a complete application, so they end up being done repeatedly in spreadsheets, scripts, or by hand.

qCalc aims to provide a simpler way.

Use a calculator—or create your own

qCalc provides a growing collection of calculators covering mathematics, engineering, science, finance, photography, everyday calculations, and many other areas.

But qCalc is not intended to be just a collection of predefined calculators.

With qCalc, you can create your own calculator using Python directly in your browser. Using its function-to-form capability, qCalc can automatically turn a Python function into a user-friendly calculator form, using the function's parameters to build the interface. You can check and validate your code, test it, and save the calculator for future use.

You write the calculation; qCalc builds the interface.

This makes it possible to turn a calculation that might otherwise live in a spreadsheet or a small script into a reusable web-based tool.

From personal calculations to shared tools

A calculator you create for yourself may also be useful to someone else.

qCalc is a platform where specialized calculators can be created, organized, used, and shared. The goal is to make it easier for people with some technical knowledge to turn their calculations into tools that others can use without needing to write code themselves.

Whether it is an engineering formula, a financial calculation, a photography tool, or a small utility for everyday work, qCalc provides a place to build it.

qCalc Philosophy

qCalc is built around a simple idea:

If a calculation is useful, it should be easy to turn it into a useful tool.

We believe sophisticated computational capabilities should be accessible without requiring everyone to build a complete software application.

qCalc is therefore designed to make calculations accessible, reusable, and practical—while providing a path for users to create tools of their own.

Free and open to everyone

qCalc is developed as a free-to-use web application, with the aim of making useful computational tools accessible to as many people as possible.

The project is continuously evolving, and the collection of calculators and capabilities will continue to grow.

Use a calculator. Create one. Make it useful to someone else.

Self-host qCalc

qCalc is also designed to be self-hosted.

Organizations and individuals can run their own qCalc installation, allowing them to create and use calculators within their own environment. This can be useful when calculators contain organization-specific formulas, procedures, standards, or other information that should remain private.

A self-hosted qCalc can provide the same calculator-building capabilities in a private environment, giving you control over your calculators, data, and deployment.

qCalc source code and self-hosting instructions are available on  Github
