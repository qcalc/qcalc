# Demonstrating Various Input Types

## Purpose

This calculator is a visual reference for the input controls available in
qCalc. It is intended for calculator authors and users who want to see how
common values, qCalc annotations, and schema-selected Django fields appear on
screen.

## Inputs

The form includes examples of text, numeric, date and time, file, table,
quantity, unit, selection, checkbox, radio, range, and multi-line inputs.
Some controls are selected from a parameter annotation; others use the
`type` setting in the calculator schema.

Use the default values to inspect each control, then change values to see its
accepted input format and interaction.

## Results

The calculator returns the submitted values as its result. It does not perform
a domain calculation or provide an interpretation of the values.

## Important Notes

This is a demonstration calculator. It can be used as a
quick reference when choosing an input type for a new qCalc calculator.
